# Voice redesign: audit, engine comparison and architecture

Applies to both apps: `nihongo-app` (Japanese) and `espanol-app` (Spanish).

## 1. Audit of the previous system

| Item | Finding |
|---|---|
| TTS engine | Only the browser's Web Speech API (`speechSynthesis`). No cloud engine, no audio files. |
| Voice choice | The highest-scoring voice by name, with no notion of region. A Mexican voice could read Castilian. If the language was missing, the system default voice was used, for example a French voice reading Spanish. |
| Parameters | Artificial pitch shifts (×1.45 "cute", ×1.75 mascot, later ×1.16), rate tweaks per "style". |
| Delivery | Live synthesis on the user's device. Every sentence was cut at punctuation with fixed 170 ms gaps. |
| Hosting limits | The apps run as claude.ai artifacts, whose content security policy blocks requests to external APIs. ElevenLabs, Azure, Google and OpenAI cannot be called from the page itself, and API keys could not be kept secret there anyway. |
| This environment | No API keys. ElevenLabs, OpenAI, Azure and Hugging Face are unreachable from the build sandbox, so no real cloud or open-source neural audio could be generated or listened to here. |

### Why it sounded robotic
1. **Old voice generation.** Windows "Desktop" voices (Haruka, Helena…) are pre-neural voices.
2. **Pitch shifting** on top of synthetic voices produced the classic chipmunk or robot artefact.
3. **Chopping** every sentence into separate utterances broke the melody the engine builds across a whole sentence.
4. **No accent control**, and a silent fallback to another language's voice.
5. **No pre-generated audio**, so quality depended entirely on the user's device.

## 2. Engine comparison

This is an assessment from vendor documentation and public comparisons. It was not measured here, because no engine was reachable. The in-app Voice Lab is the tool for measuring on real audio.

| | Azure AI Speech | Google Cloud TTS | ElevenLabs | OpenAI gpt-4o-mini-tts | Open source (Piper, Kokoro, XTTS) |
|---|---|---|---|---|---|
| Naturalness | Very high (neural) | High (Neural2, Chirp 3 HD) | Highest, most expressive | Very high | Medium |
| Regional accents | **es-ES, es-MX, es-CO, ja-JP** native voices (Elvira, Álvaro, Dalia, Jorge, Salomé, Gonzalo, Nanami, Keita…) | es-ES, es-US, ja-JP; little es-MX or es-CO coverage | Depends on the voice chosen from its library (native speakers available, quality varies) | Multilingual voices; regional accent not guaranteed and can drift | Piper has es_ES and es_MX; Kokoro has Japanese |
| Prosody control | Full SSML: rate, breaks, `express-as` styles on some voices | SSML (not for Chirp HD) | Speed, stability, style; no SSML | Plain-language instructions | Limited |
| Streaming | Yes | Yes | Yes | Yes | Local |
| Cost | Free tier, then pay per character | Free tier, then pay per character | Small free tier; paid plans | No free tier | Free |
| Fit for this app | **Best**: accent coverage and SSML, and the same voices are free inside Microsoft Edge | Good for es-ES and ja-JP, weak for es-MX and es-CO | Best for showcase dialogues and emotion; costlier | Not for accent-critical content | Offline fallback only |

**Choice:** Azure is the primary engine, because it is the only one with confirmed native voices for all four required accents plus SSML prosody control. ElevenLabs is the optional premium engine for expressive dialogues. OpenAI is not recommended where the accent must be exact.

## 3. Architecture now implemented

```
sentence → voice-engine.js
  1. audio/manifest.json has a neural recording for (accent, profile, mode)?  → play it (any browser)
  2. else: the browser's voice for exactly that accent and profile             → Web Speech, pitch 1.0
       (Edge = Azure neural voices for free; Apple Enhanced/Premium; Chrome Google voices)
  3. else: silence + explanation (open in Edge / switch to an available accent)  — never another accent
```

- **Accents** (`voice-config.js`): ja-JP (Tokyo hyōjungo); es-ES (Madrid, distinción s/θ), es-MX (Mexico City, seseo), es-CO (Bogotá, seseo). Voices are filtered by exact locale, so accents never mix.
- **Profiles:** soft and warm female, clear and lively female, calm male, deep male. Each maps to an ordered list of voices per accent, with the closest available voice used when an exact match is missing.
- **Modes:**
  - **Pedagogical**: rate 0.8 with real pauses after phrases and sentences, the slow version generated by the engine.
  - **Native natural**: the whole utterance in one piece. The pace follows the level (A1 0.84 → A2 0.9 → B1 0.95 → B2/C1 1.0 → C2 1.04).
  - **Immersion**: 1.04, no simplification.
- **Speed** is always changed at synthesis (Web Speech rate, or SSML `<prosody rate>` and ElevenLabs `speed` at generation), never by stretching audio. Pitch is never altered.
- **Pre-generated audio** (`tools/generate-audio.mjs`):
  - collects all fixed sentences (Japanese 874 sentences, about 5.3k characters per voice and mode; Spanish 535 sentences, about 10.3k)
  - generates natural and teaching renditions per voice with Azure SSML, Google, ElevenLabs or OpenAI
  - caches by content hash (only new sentences are generated) and writes `audio/manifest.json`
  - generating everything for every voice and mode is about 42k characters for Japanese and 207k for Spanish, within typical free tiers (check current pricing)
- **UI:** Me → 🎚️ Voice settings (accent, profile with ▶ preview, mode, level-adapted pace, speed, exact voice) and 🧪 Voice lab (the six test sentences, before/after on every voice, a 7-criteria score, a ranking and "Use this voice").

## 4. What was verified, and what was not

Verified here with automated browser tests using simulated voices:
- correct voice per accent and profile, and never another accent's or language's voice
- pitch always 1.0
- pace per mode and level
- pedagogical pauses
- legacy "before" mode
- generator dry run, cache, manifest
- the app playing recordings first (correct accent, teaching rendition) and falling back to Web Speech
- every existing feature in both apps (lessons, review, speaking gym, Watch & Learn, notes, writing, placement, daily plan, badges)

**Not verified:** how anything actually *sounds*. No real neural audio could be generated, and no audio can be heard in this environment. That judgement belongs to the Voice Lab, on a device with the voices.

## 5. To get native-quality audio everywhere
1. **Now, for free:** open the apps in Microsoft Edge. The Azure neural voices for every accent are built in, and the app selects them.
2. **Same quality on every browser:** create an Azure Speech resource (it has a free tier), then run:
   ```bash
   cd espanol-app && AZURE_SPEECH_KEY=… AZURE_SPEECH_REGION=westeurope node tools/generate-audio.mjs --engine azure
   ```
   Do the same in `nihongo-app`. Check the voices marked "verify" in `tools/voices.json` against the Azure voice gallery first, and publish the `audio/` folder next to the app.
3. **Premium expressive voices:** add ElevenLabs voices (native Madrid, Mexico City, Bogotá and Tokyo speakers from its library) to `tools/voices.json` and run `--engine elevenlabs`.
